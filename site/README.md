# Marketing site

Static site published at https://jschell12.github.io/scredmgr/ using GitHub Pages.

Preview locally from the repository root:

```sh
python3 -m http.server 8080 --directory site
```

Open http://localhost:8080. No build step or JavaScript dependencies are required.
DM Sans and IBM Plex Mono load from Google Fonts with local font fallbacks.
The Pages workflow deploys only this directory when site files change on main.
