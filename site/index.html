Your accounts, in context

Namespace credentials like work/github. Overlay work entries without rewriting your scripts.

A desktop companion

The Tauri GUI shows service status and expiry, guides login, and imports dotenv files. Secret-bearing commands stay in the CLI.

Connect the stores you use

Explicitly push or pull with Vault, 1Password, AWS Secrets Manager, and SSM Parameter Store. Keychain stays the canonical local store.

SSH, with less juggling

Generate keys, keep passphrases in Keychain, and register with ssh-agent. Private key files remain in your SSH directory.

Clear about its boundaries.

Good tools tell you exactly where your secrets go.

Deliberate defaults

Masked token entry. get refuses to print to a terminal. Authenticated curl requests are restricted to the configured host. Plaintext export requires an explicit opt-in.

Runtime means runtime

run passes secrets through the child process environment. That command can read them, so use it with programs you trust.

macOS first. Linux, too.

Linux uses an encrypted file store with a machine-local key, rather than Keychain. It does not protect against an attacker who can read both the key and ciphertext.

your next command.

On macOS, install Go 1.26.1 or newer and the Xcode command line tools, then build from source.

This uses ad-hoc signing for a first install. Rebuilds may prompt for Keychain access again. If you have an Apple Development signing identity, use make install instead.

Full setup and migration guide ↗
Install from source 
git clone https://github.com/jschell12/scredmgr.git
cd scredmgr
make install CODESIGN_ID=-
~/.local/bin/scredmgr --help

Add ~/.local/bin to your PATH to use scredmgr anywhere.
